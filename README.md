# Portfolio

My personal portfolio site, hosted on GitHub Pages.

## Files

- `index.html`: all the text and sections. Search for `EDIT:` to find every spot that needs your own details.
- `styles.css`: the look. Colors and fonts are set at the top under `:root`.
- `script.js`: footer year and scroll animations.
- `images/`: put project screenshots here.

## Preview locally

Open `index.html` in a browser.

## Publish a change

```
git add .
git commit -m "Describe the change"
git push
```

The live site updates a minute or two after each push.
